## inコマンド
- ハードリンク、シンボリックリンクがある
- inコマンドはリンクを貼るコマンド
### リンクを貼るとは？
- ファイルに別名をつけること。
### ハードリンク、シンボリックリンク
- 大体はシンボリックリンク
- ハードリンク
  - 一つのファイルの実体に複数の名前をつける機能
    ```
    cp /etc/crontab file1
    ls
    #file1
    in file1 file2   ハードリンクfile2を作成
    ls
    #file1 file2　　　fike2ができた


    cat file2
    #(file1の内容が表示される)
    ```
  - ハードリンクで複数の名前がついているファイルの削除
    ```
    rm file1
    ls
    #file2   ハードリンクで作ったファイルが残っている
    cat file2
    #(file1の内容が表示)
    rm file2
    ls
    nono   全てのハードリンクがなくなったため、ファイル実体も削除された。
    ```
- シンボリックリンク
  - リンク先のパスが書かれた小さな特殊ファイル
    ```
    in -s file1 file2 #-sオプションをつけることでシンボリックリンクを作成できる
    cat file2
    #file1の内容が出る
    ```
  - シンボリックリンクを削除
    ```
    rm file2
    ls
    #(file1)
    ```
  - 壊れたシンボリック
    ```
    rm file1
    ```
  ###  リンク先をしめすfile2を消しても問題はないがリンク先である実体のfile1を消してしまうと全て消えてしまう。

- ハードリックとの違い
  - リンク先がファイルの実体であり本物のファイル。
 
### リンクの使い道
- 長い名前のパスめいを省略する
   ```
   in -s local/?/+/*/+++/  +++
   cd +++
   ```

## ファイルを調べる
- ファイルを探す
### find<検索開始ディレクトリ><検索条件><アクション>
- ``` find . -name file-1.txt -print  ```
  - .(検索開始ディレクトリ)-name file-1.txt(検索条件)-print(アクション)
 - 検索開始ディレクトリを起点として条件を満たすファイルを探しアクションを実行する。
 - 検索条件に何も指定しなかった場合全てのディレクトリやファイルが対象となる
 - アクションを指定しないと-printになる
### ファイル名で探す場合
 - -nameは大文字小文字を区別するが-inameは区別しない。それ以外は同じ
 - ※や？をつ買う場合必ず''でかこむ。
### ファイルの種類で探す(-type)
|指定|ファイル種類|
|---|---|
|-type f|通常ファイル|
|-type d|ディレクトリ|
|-type l|シンボリックリンク|

``` find -type d -print #カレントディレクトリの下にあるディレクトリを列挙 ```
- 複数の検索条件の指定(-a)
``` find .-type f -a -name '*.txt' -print
#-aで検索条件を追加する。-a = AND
   ```
