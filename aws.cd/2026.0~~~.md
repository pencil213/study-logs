## httpについて
- httpメソッド
  - from method="GET"コンテンツの取得
  - from method="POST"クライアントからサーバーに向かって送信するデータ
- httpステータスコード
  - 1xx　処理中
  - 2xx　成功
  - 3xx　リダイレクト
  - 4xx　クライアントエラー　
  - 5xx　サーバーエラー
## レスポンスヘッダー
- コンテンツヘッダー
  - content-type:text/html
  - textをhtmlで表示する

- NAtGWはあるだけでお金がかかるから使い終わったら消す
- curl url でDBサーバーからnatGWを通してインターネットのwebにアクセスできる

- sudo cp -r * /var/www/html/ フォルダーの中身ごとコピー
- sudo chown apache:apache /var/www/html -R　上と同じだがchownでは-Rを使う
- telnet 宛先ホスト名かipアドレス　ポート番号　特定のポート番号の通信確認
- nslookup 名前解決の確認
