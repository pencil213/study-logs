### コマンドラインの応用操作
---
```
変数の定義
export num="hellow"
出力
echo num
環境変数の確認
env
```
###　コマンド履歴の活用
- history
  - これまで実行したコマンドを一覧表示
- !!
  - 直後に実行したコマンドをもう一度実行
### コマンドの実態を調べる
- type コマンド
  - コマンドの種類を判定
### コマンド終了ステータス
- $?
   - 直前のコマンドの結果を確認
   - 0.実行
   - 2.エラー
- cmd1 && cmd2コマンド1が成功したらコマンド２を実行
- cmd1 || cmd2 cmd1が失敗したらcmd2を実行
- cmd1 ; cmd2成否にかかわらずに順番に実行
