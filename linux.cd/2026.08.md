### 8/7
## やったこと
- mkdir -p (PEARENT)　二つのディレクトリを一気に作成
- rmdir -p 
- tar -cf(creat,file)アーカイブファイルの作成、fileの指定 , -tf(list,file)アーカイブファイルの参照*lsではアーカイブファイルの中身が見れない, -xf (extract抽出)アーカイブファイから外して普通のファイルにする。だからlsで表示できる
## コマンド
```
mkdir -p test1/test2 
ls 
rmdir -p test1/test2
ls
(test.txt test2.txt test3.txt)
tar -cf test.tar test*
tar -tf test.tar
(test.txt test2.txt test3.txt)
tar -xf test.tar
ls
(test.txt test2.txt test3.txt)
```

### 8/14
## やったこと
- パーミッションの変更
- 権限の追加
- chmod 400 (ファイル名）
  - 左から所有者、グループ、その他。4=読み取り、0=何も権限がない
- 権限の削除
  - chmod ug-w(write) test2.txt
- changemodeコマンド
  - chmod　400 ~~~
-　所有者の変更
- chown(チェンジオーナーコマンド)
  - ファイル、ディレクトリの所有者が変更される。
  - chown -R ユーザー名　ディレクトリ(ディレクトリの所有者とその中身のファイルの所有者も変更される)
## コマンド
```
ls -l test*
(-「ファイルの種類」rw「所有者」-r--r--「その他」~~~test1
(-rw-r--r--~~~test2
chmod 400 test.txt(権限変更)
chmod ug-w test2.txt(全てのユーザーからwrite権限の削除)

sudo useradd testuser
sudo chown testuser test1(テスト1の所有者がubutunからtestuserになった)
(sample1/test1)
sudo chown -R testuser　sample1
(ディレクトリの所有者とその中身の所有者が変更)

```
