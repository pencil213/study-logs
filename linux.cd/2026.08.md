
### 8/20
## やったこと
- その他のアクセスモード
 - suid 
   - 設定すると所有者権限で実行できる
   - chmod 4xxx ファイル/ディレクトリ
   - chmod u+s ファイル/ディレクトリ
 - sgid
   - 設定すると所有グループ権限での実行ができる
   - chmod 2xxx ファイル/ディレクトリ
   - chmod g+s ファイル/ディレクトリ
 - スティッキービット
   - 所有者でのみ削除可能にする
   - chmod 1xxx ファイル/ディレクトリ
   - chmod o+t ファイル/ディレクトリ


- ハードリンクとシンボリックシンボル
-リンクの種類
 - ハードリンク
   - 元のファイルが削除されてもデータにアクセス可能(ファイルとリンクが非結合でそれぞれノードに繋がってる
   - ファイル→ノード←リンク
 - シンボリックリンク
   - ディレクトリ宛のリンクが作れる
   - リンク→ファイル→ノード
- リンクの作成
 - inコマンド
   - リンクの作成
   - ln オプション(f,s)　リンク元　リンク
   - シンボリックリンクの作成
     - ln -s ~~~ ~~~
 ## コマンド
 ```
cat test/sample.txt
(test link)
ln test/sample.txt hard.ln
(hard.lnという名前のリンクを作成)
ln -s test/sample.txt symbol.txt
(シンボリックリンクを作成)
echo hellow >> test/sample.txt
( test link hellow )
ln test testdir.ln
(ハードリンクじゃディレクトリ宛のリンクは作れない）
ln -s test testdir.ln
(シンボリックリンクはディレクトリ宛のリンクが作れる）
```
