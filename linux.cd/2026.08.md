- ハードリンクとシンボリックシンボル
-リンクの種類
 - ハードリンク
   - 元のファイルが削除されてもデータにアクセス可能(ファイルとリンクが非結合でそれぞれノードに繋がってる
   - ファイル→ノード←リンク
 - シンボリックリンク
   - ディレクトリ宛のリンクが作れる
   - リンク→ファイル→ノード
- リンクの作成
 - inコマンド
   - リンクの作成
   - ln オプション(f,s)　リンク元　リンク
   - シンボリックリンクの作成
     - ln -s ~~~ ~~~
 ## コマンド
 ```
cat test/sample.txt
(test link)
ln test/sample.txt hard.ln
(hard.lnという名前のリンクを作成)
ln -s test/sample.txt symbol.txt
(シンボリックリンクを作成)
echo hellow >> test/sample.txt
( test link hellow )
ln test testdir.ln
(ハードリンクじゃディレクトリ宛のリンクは作れない）
ln -s test testdir.ln
(シンボリックリンクはディレクトリ宛のリンクが作れる）
```
### 8/26
## やったこと
- topコマンド
  - メモリや CPU についてのシステム情報
  - 先頭の行は、システムの起動時刻、稼働時間、ログインしているユーザー数、CPU の平均負荷率を表す
　- cPU の平均負荷率は、左から過去 1 分、5 分、15 分間の平均負荷率を表しています。
　- uptime コマンドでも確認可能
- ジョブ：コマンドの集まり
  - フォアグラウンドジョブ(デフォルト):一つのジョブでシェルを占有する
    - fg ジョブ番号　fgに変更
  - バックグラウンドジョブ:複数のジョブを一つのシェルで同時にできる
    - bg ジョブ番号　bgジョブに変更
- 現在処理中のジョブを表示
  - jobsコマンド
## コマンド
```
top
./sleep.sh &
(バックグラウンドでジョブを実行)
jobs
([1]+  Running                 ./sleep.sh &)

./sleep.sh
control z
(ジョブの停止)
bg 1
(bgジョブに変更)
```
