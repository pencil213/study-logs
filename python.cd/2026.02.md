- for文とwhile文の使い分け
 - 繰り返し回数が何となく決まっているならwhile文、決まっていない目処が立っていない場合for文
- contineとbreakの使い分け
 - リストの中で何回繰り返すとかわかっている場合はbreakを使い、条件と違う場合だけその繰り返しを飛ばして次の繰り返しに映るのがcontineを使う。

## コード
- for文による九九
- ```for n in range(9):  
   for i in range(9):  
    print(f'{n+1}×{i+1}={(n+1) * (i+1)}')```
- 奇数の段を飛ばす  
  ```for i in range(9):  
    if (i+1)%2==0:  
         continue  
    for n in range(9):  
        print(f'{i+1}×{n+1}={(i+1) * (n+1)}')
  ```
