## 2026/04/14

### ElastiCache（for Redis）
- キャッシュとして利用し高速化
- DB負荷軽減

### Amazon EFS
- 複数EC2からアクセス可能な共有ファイルシステム

### S3
- オブジェクトストレージ
- インターネット経由で直接アクセス可能
- 自動スケーリング

### AWS Snowball Edge
- 物理デバイスで大容量データ転送

### S3 Glacier
- 低コスト長期保存
- 取り出しに時間がかかる

### Amazon DynamoDB
- NoSQL（キー・バリュー）
- 高速・スケーラブル

### AWS Lambda
- サーバーレス実行
- イベント駆動

### Amazon EMR
- Hadoopベースのビッグデータ

## 2026/04/16

### Amazon Redshift
- データウェアハウス（分析用）

### AWS Config
- リソース構成の監査・記録

### AWS Cloud9
- クラウドIDE（開発環境）

### AWS Code系
- CI/CD構築に使用

### AWS App Runner
