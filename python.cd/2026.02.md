  ## 2/18
  ## 引数と戻り値
  - 定義された関数と元の世界の関数は名前は同じでも別の関数
  - ```
    def input_score():
    name = ''
     print(f'{name}の点数を入力してください'）
    ```
    と
    ```
    name=佐藤
    input_score()
    ```
    のnameは別の関数なためエラーが起こる
  ## 解決するために
  - 引数
  - ```
    def input_score(name):
     print (f'{name}の得点を入力してください')
    ```
    ```
    input_score('佐藤')
    ```

  ## 戻り値
  - 関数から呼び出し元へデータを返すこと
  - ```
 def 関数名(引数１、引数２)
    　処理
　　  return 戻り値
    ```
  - 戻り値は一つのみ
  - ```
    ##足し算
    def plus(x,y)
     answer = x+y
     return answer

    answer = plus(50,100)
    print(f'得点は{answer}です')
    ```
