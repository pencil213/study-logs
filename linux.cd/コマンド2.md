---
```
変数の定義
export num="hellow"
出力
echo num
環境変数の確認
env
```
###　コマンド履歴の活用
- history
  - これまで実行したコマンドを一覧表示
- !!
  - 直後に実行したコマンドをもう一度実行
### コマンドの実態を調べる
- type コマンド
  - コマンドの種類を判定
### コマンド終了ステータス
- $?
   - 直前のコマンドの結果を確認
   - 0.実行
   - 2.エラー
- cmd1 && cmd2コマンド1が成功したらコマンド２を実行
- cmd1 || cmd2 cmd1が失敗したらcmd2を実行
- cmd1 ; cmd2成否にかかわらずに順番に実行

###  テキストフィルターのファイル処理
---
- ログやscvなどのデータを加工する
### よく使うフィルタコマンド
- cut 指定した区切りや文字やカラムでテキストを取り出す。
- sort 行を並び替える
- uniq 連続する重複行をまとめる
- tr 文字を別の文字に変換.削除する
- wc 行数、単語数、文字数を整える
### sed ストリームエディタ
- ファイルを開かずにテキストの置換や削除を行う
```
touch file.txt
nano file.txt
  food
  apple
  orenge
sed 's/food/foods/' file.txt
```
* sed 's/変更前/変更後/' ファイル名
