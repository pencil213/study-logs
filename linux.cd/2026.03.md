### ファイル操作の基本
## inコマンド
- ハードリンク、シンボリックリンクがある
- inコマンドはリンクを貼るコマンド
### リンクを貼るとは？
- ファイルに別名をつけること。
### ハードリンク、シンボリックリンク
- 大体はシンボリックリンク
- ハードリンク
  - 一つのファイルの実体に複数の名前をつける機能
    ```
    cp /etc/crontab file1
    ls
    #file1
    in file1 file2   ハードリンクfile2を作成
    ls
    #file1 file2　　　fike2ができた


    cat file2
    #(file1の内容が表示される)
    ```
  - ハードリンクで複数の名前がついているファイルの削除
    ```
    rm file1
    ls
    #file2   ハードリンクで作ったファイルが残っている
    cat file2
    #(file1の内容が表示)
    rm file2
    ls
    nono   全てのハードリンクがなくなったため、ファイル実体も削除された。
    ```
- シンボリックリンク
  - リンク先のパスが書かれた小さな特殊ファイル
    ```
    in -s file1 file2 #-sオプションをつけることでシンボリックリンクを作成できる
    cat file2
    #file1の内容が出る
    ```
  - シンボリックリンクを削除
    ```
    rm file2
    ls
    #(file1)
    ```
  - 壊れたシンボリック
    ```
    rm file1
    ```
  ###  リンク先をしめすfile2を消しても問題はないがリンク先である実体のfile1を消してしまうと全て消えてしまう。

- ハードリックとの違い
  - リンク先がファイルの実体であり本物のファイル。
 
### リンクの使い道
- 長い名前のパスめいを省略する
   ```
   in -s local/?/+/*/+++/  +++
   cd +++
   ```
   local/?/+/*/+++/という深いパスを持つディレクトリやファイルを+++短いリンクを作ることで打つのが短くすむし、ミス辛くなる
