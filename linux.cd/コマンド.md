パーティションとファイルシステム
---
新しいディスクを使えるようにするには[パーティションを切る][ファイルシステムを作る]が必要
パーティションテーブル
- MBR　古い　　4つまで
- GPT 新しい　128個までパーティションを作れる

### パーティションの作成 fdisk/parted
```
sudo fdisk /dev/sdb #対話形式でパーティション操作

(command(m for help)) ここでn p w などのサブコマンドを入れていく　　これが対話形式

⚠️wで変更を書き込むと元に戻せない。デバイス名を間違えていないか実行前に必ず確認するべし。

sudo parted /dev/sdb print
(Partition Table:gpt)#このディスクがGPTとわかる
```
### ファイルシステムの作成
- パーティションを作成しただけでは使えないのでmkfsでファイルシステムを書き込む
- ext4　長年使われている標準のファイルシステム
- xfs　大容量ファイルの扱いに強い
- btrfs　スナップショットなどの高度な機能を持つ
```
sudo mkfs.extf4 /dev/sdb1
sudo mkfs.xfs /dev/sdb2


```
### LVM
- LVMは複数のディスクを一つのプールとして考える
- PV　物理ディスクやパーティション
- VG　複数PVをまとめたプール
- LV VGから切り出した実際にマウントする単位

### スワップ領域の作成
- 物理メモリが不足した場合に一時的にデータを退避させる領域
```
sudo mkswap /dev/sdb3
sudo swapon /dev/sdb3 #スワップの有効化
swapon --show #現在有効なスワップ領域を確認
sudo swapoff /dev/sdb3　#スワップを無効化
```

### mkfsの主なオプション
```
sudo mkfs.ext4 -L date -b 4096 /dev/sdb1
(-L ラベル名　-b ブロックサイズの指定)
sudo mkfs.xfs -f /dev/sdb2
(-f 強制的に上書きする
```

### inodeの考え方
-　ディスクにはデータとは別にinodeと言われる管理情報が割り当てられる
```
df -i
(各ファイルのinodeの使用状況を確認できる)
(ディスク(ファイル))
-T　ファイルシステムの種類もかぶせて表示(Tipe)
-i アイノードの使用状況を表示
```

ファイルシステムマウントと整合性
---
### mount/umount
```
 sudo mount /dev/sdb1 /mnt/date　#/dev/sdb1を　/mnt/dateにマウント
 mount #現在のマウント中の一覧を表示
 sudo umount /mnt/date #アンマウント
 blkid /dev/sdb1 #uuidなどを表示する。
```
### 容量　ファイルシステムの状態を確認
```
df -h (human readable)#マウントされているファイルシステムごとの空き容量を確認 人間が読みやすようにしている
du -sh ディレクトリ　(summarize)#指定ディレクトリの合計の使用容量を集計
```
### 代表的なマウントオプション
- ro  読み取り専用でマウント
- rw　読み書き可能でマウント
- noexec　実行禁止にする
- nosuid　suidの無効化
- nodev　デバイスファイルとしての解釈を禁止
- defalt　標準的な設定をまとめて指定

パッケージの管理と運用

---
### dpkgDevian系の低レベル操作
```
sudo dpkg -i package.deb #debファイルを直接インストール
dpkg -l #インストール済みのパッケージ一覧
dpkg -L nginx #nginxが持つファイルを一覧表示
dpkg -r nginx #nginxのファイルを削除

```
### rpm red Hat系の低レベル操作
```
sudo rpm -ivh package.rpm #インストールi verbose--v 進捗表示--h
rpm -qa #パッケージ一覧　qクエリ（データベースに検索とかしてもらうこと)-a all
rpm -ql httpd #httpdが持つファイルを一覧表示
sudo rpm -e httpd #erase 削除
```

|操作|Debian系|red Hat系|
|---|---|---|
|ファイルからインストール|dpkg -i|rpm -ivh|
|依存関係解決込みでインストール|apt install |dnf install|
|一覧表示|dpkg -l|rpm -qa|
|検索|apt search|dnf search|
