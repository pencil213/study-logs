# EC2 続き　
## OSを管理者権限で操作できる
- 起動したec2インスタンスでは、AWS symple managerのセッションマネージャーやsshを使用してosを管理者権限で操作できる。
  - sshとは自分のpcからec2サーバーに安全にアクセスするためのもので鍵を持つ。また、そこからターミナルで操作していく。
  - セッションマネージャーとはAWS symple managerの中の機能の一つでsshを使用しなくてもec2サーバーにアクセスできる
### セッションマネージャー
AWSsymplemanagerの機能の一つ。三つの前提条件のもとで使用できる。
- 使用条件
  - SSMAgentがOSにインストールされている。
    - SSMAgentはほとんどのクイックスタートAMIに入っている。
    - SSM Agent = EC2とAWS管理サービスをつなぐ橋でEC2の中で動く小さなプログラム

  - EC2インスタンスがsystemmanagerで管理できるようにIAMロールを引き受けている
  - EC2インスタンスからのリクエスト送信がSystemMnagerのエンドポイントに到達できる
- OSに安全に接続できて、管理者権限で操作できる。
