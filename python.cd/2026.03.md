##　可変長引数を利用した関数定義
- ```
  def 変数名(仮引数１、仮引数２、＊仮引数n)
  ```
  - n個以上の引数を呼び出せる
  - n引数以降の引数は一つのタプルとして受け取る
- 例
 ```
  
  def eat2(breakfast,lunch,dinner='カレー',*dezerts):  
 print(f'朝は{breakfast}を食べました')  
 print(f'昼は{lunch}を食べました')  
 print(f'夜は{dinner}を食べました')  
 for d in dezerts:  
  print(f'おやつに{d}を食べました')  
eat2('トースト','カレー','パスタ','アイス','ちょこ','みかん')

   ```
