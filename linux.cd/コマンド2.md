### コマンドラインの応用操作
---
```
変数の定義
export num="hellow"
出力
echo num
環境変数の確認
env
```
###　コマンド履歴の活用
- history
  - これまで実行したコマンドを一覧表示
- !!
  - 直後に実行したコマンドをもう一度実行
### コマンドの実態を調べる
- type コマンド
  - コマンドの種類を判定
### コマンド終了ステータス
- $?
   - 直前のコマンドの結果を確認
   - 0.実行
   - 2.エラー
- cmd1 && cmd2コマンド1が成功したらコマンド２を実行
- cmd1 || cmd2 cmd1が失敗したらcmd2を実行
- cmd1 ; cmd2成否にかかわらずに順番に実行

###  テキストフィルターのファイル処理
---
- ログやscvなどのデータを加工する
### よく使うフィルタコマンド
- cut 指定した区切りや文字やカラムでテキストを取り出す。固定区切り
- sort 行を並び替える
  - n文字列ではなく数値として比較する
  - r逆順
  - k　n番目列
  - u unit(重複行の削除)
- uniq 連続する重複行をまとめる
- tr 文字を別の文字に変換.削除する
- wc 行数、単語数、文字数を整える
### sed ストリームエディタ
- ファイルを開かずにテキストの置換や削除を行う
```
touch file.txt
nano file.txt
  food
  apple
  orenge
sed 's/food/foods/' file.txt

sed '2d' file.txt
(二行目を削除)
sed '2,4d' file.txt
(2-4行めを削除)
```
* sed 's/変更前/変更後/' ファイル名

### awk 列指向のテキスト処理
```
awk -F: '{print &1}' /etc/passwd
(各行の一列目を:区切りで表示)
```
### diff 二つの差分
```
diff file1 file2
(hello
---
worlds)
```
### join
```
join file1 file2
(ソートされた列のファイルを共通のキー列で結合する)
```
### tr 一文字づつの変換や削除
```
echo "hello world" | tr 'a-z' 'A-Z'
(小文字から大文字に変換)
echo "a b.   c"  |tr -s " "
(連続する空白を一文字に変換)
cat file.txt | tr -d '/r'
(指定文字を削除)
```
