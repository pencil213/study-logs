### 8/7
## やったこと
- mkdir -p (PEARENT)　二つのディレクトリを一気に作成
- rmdir -p 
- tar -cf(creat,file)アーカイブファイルの作成、fileの指定 , -tf(list,file)アーカイブファイルの参照*lsではアーカイブファイルの中身が見れない, -xf (extract抽出)アーカイブファイから外して普通のファイルにする。だからlsで表示できる
## コマンド
```
mkdir -p test1/test2 
ls 
rmdir -p test1/test2
ls
(test.txt test2.txt test3.txt)
tar -cf test.tar test*
tar -tf test.tar
(test.txt test2.txt test3.txt)
tar -xf test.tar
ls
(test.txt test2.txt test3.txt)
```

##やったこと
- fileの圧縮と解凍
  - xzコマンド
  - xz圧縮,xz -d解凍
  - file ../~~~~~圧縮形式の確認
##  コマンド
```
tar -cf sample.tar test*
xz sample.tar
ls -l sample*
(sample.tar.xz圧縮)
file sample.tar.xz
(圧縮形式の確認xz)
xz -d sample.tar.xz
(解凍）
tar -xf sample.tar
(抽出)
```
